# Scripts & Specialized Tools

데이터시트 지식 그래프(HKG) 구축, PDG 시각화 등 특정 태스크를 위한 유틸리티 스크립트 모음입니다.

* **`run_build_ads7891_kg.py`**: ADS7891 SAR ADC 데이터시트로부터 HKG 지식 그래프 및 PDG 추출 파이프라인.
* **`run_build_ref30e_pdg.py`**: REF30E 전압 레퍼런스 PDG 구축 및 ParseBench 감사 파이프라인.
* **`visualize_pdg.py`**: 데이터시트 PDF로부터 포트 의존성 그래프(PDG)를 추출하고 독립형 인터랙티브 HTML로 시각화하는 CLI 도구.
